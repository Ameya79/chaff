## Context & Problem
AI landing page generators universally rely on identical purple-to-blue radial glow spheres (`blur-3xl bg-purple-500/30`) positioned behind hero sections. It creates synthetic contrast without structural hierarchy, blurs text readability, and produces immediate visual fatigue. This ubiquitous neon glow look immediately signals to users that the interface is an uncurated template rather than thoughtfully authored software.

## Detection Logic
Static AST and regex scanner flags Tailwind classes matching `(?:bg-gradient-to-[a-z]+|from-(?:purple|indigo|violet)-\d{3}\s+to-(?:blue|cyan)-\d{3})`, as well as absolute elements combining `rounded-full` with `blur-(?:2xl|3xl)` and purple or indigo background colors. The audit also detects inline SVG radial gradients with purple-to-blue stop colors used as decorative background canvas backdrops.

## Remediation Steps
1. Delete decorative blurred orb containers and radial neon gradients from the DOM.
2. Replace stark black `#000000` with curated tinted dark surfaces (such as `bg-stone-950` or `bg-zinc-950`).
3. Establish visual hierarchy using typographic scale, deliberate font weights, and subtle 1px semantic borders (`border-stone-800/60`).
4. If accent color is required, restrict it to semantic interactive controls, active indicators, or restrained monochromatic tints.

## Verification
Run static scanner asserting zero matches for `blur-3xl` combined with purple or indigo color tokens across component files. Verify computed surface colors adhere to semantic theme tokens rather than raw neon gradients.
