## Context & Problem
Over 90% of AI-generated SaaS landing pages share an identical visual structure: a centered headline, a centered subtitle paragraph, two centered pill buttons (primary colored and secondary outline), followed immediately by a three-column grid of equal-sized cards with icons. This symmetric boilerplate pattern lacks domain authenticity, feels instantly generic, and fails to reflect the unique data architecture of the underlying application.

## Detection Logic
Headless Playwright rendered layout audit examines hero section DOM geometry: checks for a centered heading element paired with two centered action buttons, followed immediately by a three-column CSS grid where all three child containers have identical bounding box aspect ratios and widths.

## Remediation Steps
1. At Level 2 (Authored) and Level 3 (Risk), replace the cookie-cutter symmetrical hero layout with an authored asymmetric composition (for example, a 7-column editorial headline paired with a 5-column live interactive data widget).
2. Replace the three identical feature cards with domain-authentic representations: an index table, interactive code sandbox, live terminal view, or structured ruled ledger.
3. Replace generic pill button clusters with contextual primary action flows integrated naturally into the narrative layout.

## Verification
Playwright geometric layout evaluation verifies that the hero section does not match the centered headline plus two buttons plus three-equal-card grid fingerprint.
