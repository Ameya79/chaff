## Context & Problem
Browsers wrap multi-line heading text greedily by default, filling the first line to maximum container width and pushing one or two remaining words onto a lonely final line. These typographic widows look clumsy and unpolished, breaking the visual rhythm of prominent hero and section titles.

## Detection Logic
Static AST scanner inspects all `<h1>` through `<h4>` tags and elements with heading ARIA roles or font size utilities `text-2xl` and above. If the element lacks `text-balance` (Tailwind utility) or the CSS declaration `text-wrap: balance` / `text-wrap: pretty`, it is flagged.

## Remediation Steps
1. Add `text-balance` to heading tags in Tailwind CSS configurations.
2. In CSS stylesheets, declare `text-wrap: balance;` on all heading selectors (`h1, h2, h3, h4`).
3. For longer subtitles or multi-line card titles, consider `text-wrap: pretty` to prevent typographic orphans.
4. Verify graceful fallback on legacy browsers where un-balanced greedy wrapping remains standard behavior.

## Verification
Static scanner verifies the presence of `text-balance` or `text-wrap: balance` on all primary heading declarations. Visual inspection at 390px and 1440px confirms harmonious line breaks without single-word trailing lines.
