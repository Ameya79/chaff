## Context & Problem
Centering prose forces readers to seek a new starting anchor for every line. While short one-line headlines look acceptable centered, multi-line body paragraphs create ragged edges on both sides, disrupting natural left-to-right eye saccades. AI page templates center entire blocks of narrative text by default, resulting in poor readability and fatigue.

## Detection Logic
Headless Playwright rendered audit queries all `<p>` elements with computed `text-align: center`. If `clientHeight` divided by computed `lineHeight` exceeds 2.5 (indicating 3 or more wrapped lines), flag a violation. In static fallback mode, the scanner flags paragraph tags combining `text-center` with inner text length exceeding 120 characters.

## Remediation Steps
1. Remove `text-center` from paragraph tags and replace with `text-left`.
2. In centered hero sections, keep the headline centered if appropriate, but wrap supporting prose in a left-aligned container with constrained width (`max-w-xl text-left mx-auto`).
3. Set line height to a relaxed reading cadence (`leading-relaxed` or line-height: 1.625).
4. Restrict line length to between 45 and 75 characters (`max-w-prose`).

## Verification
Playwright assertion verifies every visible paragraph element with line count of 3 or greater has computed `text-align` equal to `left` or `start`. Confirm comfortable eye tracking across 390px and 1440px viewport widths.
