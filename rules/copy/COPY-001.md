## Context & Problem
Language models default to synthetic marketing hyperbole when tasked with creating software copy. Clichés such as 'unleash', 'supercharge', 'elevate', 'revolutionize', 'seamless', 'next-gen', and 'effortlessly' provide zero concrete technical information about the product's capabilities, inputs, or outputs. Experienced developers instantly recognize these phrases as machine-generated boilerplate and distrust the underlying software.

## Detection Logic
Static regex scanner inspects JSX text nodes, markdown files, and static copy strings for common synthetic marketing buzzwords using the pattern:
`\b(?:unleash|supercharge|elevate|revolutionize|seamless(?:ly)?|next-gen(?:eration)?|game-changing|effortless(?:ly)?|cutting-edge|reimagine|re-invent|harness the power|unlock your potential)\b` (case-insensitive).

## Remediation Steps
1. Delete empty marketing buzzwords, hyperbolic adjectives, and inflated verbs from headlines and value propositions.
2. Replace vague promises with precise technical actions and measurable outputs: describe the exact mechanism, file format, timing, or protocol.
3. State what the application accomplishes directly using active verbs like 'compile', 'verify', 'bundle', 'inspect', or 'deploy'.
4. Ensure claims are factually verifiable through project code or benchmarks.
